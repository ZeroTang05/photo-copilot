# 编辑状态与渲染技术规格

## 版本与基本类型

schemaVersion 固定为 1，rendererVersion 固定为 pc-render-1。所有数值必须是有限数。枚举外字段与未知对象字段均拒绝。数值输入在 UI 层按步长规范化，模型输出在校验阶段按相同步长四舍五入，舍入后重新校验范围。超范围值整体拒绝。

UUID 用于 imageId、requestId、planId 和 regionId。JSON 为交换格式，以下字段表为实现 Schema 的规范来源。

## EditState

| 字段 | 类型 | 契约 |
| --- | --- | --- |
| schemaVersion | 整数 | 固定为 1 |
| rendererVersion | 字符串 | 固定为 pc-render-1 |
| imageId | UUID | 当前规范化图像的会话身份 |
| revision | 非负整数 | 每次提交、撤销、重做、重置均递增，禁止回退 |
| sourceWidth、sourceHeight | 正整数 | EXIF 方向规范化后的像素尺寸 |
| global | GlobalAdjustments | 全部 7 个参数必填 |
| transform | Transform | angleDeg、crop、aspectLock |
| regions | Region 数组 | 最多 4 个，按创建顺序保存 |

资源像素、历史、AI 会话和画布视口均存放在 EditState 之外。revision 表示状态提交序列，不等同于历史光标。

## 全局与局部参数

| 参数 | 范围 | 默认值 | 步长 | 可用范围 |
| --- | --- | --- | --- | --- |
| exposureEV | 负 2 至正 2 | 0 | 0.01 | 全局与局部 |
| contrast | 负 100 至正 100 | 0 | 1 | 全局 |
| highlights | 负 100 至正 100 | 0 | 1 | 全局与局部 |
| shadows | 负 100 至正 100 | 0 | 1 | 全局 |
| warmth | 负 100 至正 100 | 0 | 1 | 全局 |
| tint | 负 100 至正 100 | 0 | 1 | 全局 |
| saturation | 负 100 至正 100 | 0 | 1 | 全局与局部 |

局部 adjustments 固定包含 exposureEV、highlights、saturation，默认均为 0。不支持的局部参数构成非法计划。

## 规范化与色彩

导入允许浏览器可解码的 JPEG、PNG、WebP、AVIF、GIF，以及 TIFF 和相机 RAW。TIFF 由 UTIF 解码；RAW 由 LibRaw WebAssembly 在浏览器内去马赛克并输出 sRGB 像素。先检查文件类型、尺寸和像素预算，再解码。损坏文件由实际解码结果判定失败。

使用 createImageBitmap 的 from-image 方向处理，保持默认颜色转换，将结果绘制到显式 sRGB 的 Canvas 2D。完成后尺寸和坐标均以该画布为准，禁止再次套用 EXIF 旋转。浏览器颜色管理结果作为规范化输入，不手工重复应用 ICC。

透明输入在 sRGB Canvas 2D 上合成到白底，规范化后 alpha 固定为 1。界面在导入时说明透明区域使用白底。支持范围为 SDR；有明确 HDR 标记的输入显示不支持，没有识别出的特殊输入按浏览器 SDR 解码结果处理且不承诺 HDR 保真。

规范化资源为 8 位 sRGB。色彩转换能力按 [MDN createImageBitmap](https://developer.mozilla.org/en-US/docs/Web/API/Window/createImageBitmap) 和真实 ICC、EXIF 样本验证。原文件二进制保留用于当前会话资源生命周期，永不覆盖。

## 固定渲染顺序

输出像素映射回规范化原图坐标，采样后依次执行 sRGB 解码、全局白平衡、曝光、明暗分区、饱和度、对比度、局部调整、sRGB 输出编码。裁切与旋转改变采样坐标，蒙版在规范化原图坐标上求值。

规范中的 clamp 表示限定到指定区间，mix 表示线性插值，smoothstep 表示三次平滑阶跃。所有色彩运算使用 highp 浮点。

### sRGB 与采样

通道 s 不大于 0.04045 时，线性值为 s / 12.92。其余情况为 pow 函数作用于底数 s 加 0.055 后除以 1.055，指数为 2.4。

线性通道 c 不大于 0.0031308 时，编码值为 12.92 乘 c。其余情况为 1.055 乘 c 的 1 / 2.4 次幂再减 0.055。负线性值在编码前限制为 0，最终输出限制在 0 至 1。

原图使用 RGBA8 纹理和 NEAREST 采样，由着色器读取四个相邻 texel，逐个转换为线性 RGB 后做双线性插值。四点位于像素中心，越过图片最外一行或一列时夹取边缘 texel。这样避免不同管线的自动 sRGB 转换与编码域插值差异。

### 全局调整

令 w 为 warmth / 100，t 为 tint / 100。R、G、B 增益分别为 2 的 0.25w 次幂、2 的负 0.20t 次幂、2 的负 0.25w 次幂。对增益使用 0.2126、0.7152、0.0722 的加权均值归一化，使中性灰亮度保持稳定。原 RGB 乘相应增益，再乘 2 的 exposureEV 次幂。

亮度 Y 为线性 RGB 按 0.2126、0.7152、0.0722 加权求和。以下权重使用限制在 0 至 1 的 Y。阴影权重为 1 减 smoothstep 在 0.05 与 0.50 之间对 Y 的结果。高光权重为 smoothstep 在 0.45 与 0.95 之间对 Y 的结果。

明暗分区的局部 EV 为 shadows / 100 乘阴影权重，加 highlights / 100 乘高光权重。RGB 乘 2 的该 EV 次幂。阴影和高光权重在该步骤开始时求一次，两项同时合成。

饱和度系数为 1 加 saturation / 100。以当前亮度 Y 为灰色基准，每通道计算 Y 加系数乘该通道与 Y 的差。负值限制为 0。

对比度先将线性 RGB 编码到 sRGB，使用 0.5 枢轴。每通道计算 0.5 加该通道减 0.5 后乘以 2 的 contrast / 100 次幂，结果限制到 0 至 1，再解码回线性 RGB。此时的 RGB 记为全局基准 G。

这是具有固定版本的基础色调算子。其阴影提亮可能增加已有噪点，高光压暗无法恢复已丢失信息。G0 评估自然度达标后冻结该版本。

### 局部蒙版与局部合成

Region 包含 id、label、enabled、centerX、centerY、radiusX、radiusY、feather、shape 和 adjustments。shape 为 ellipse、linear 或 brush；线性渐变使用 angleDeg，画笔使用最多 32 个 brushDabs 与 brushRadius。label 长度为 1 至 40 字符，enabled 为布尔值。中心范围为 0 至 1，半径范围为 0.01 至 1，feather 范围为 0.05 至 1，几何步长为 0.0001，feather 步长为 0.01。椭圆可以跨出图片边缘，中心必须落在图片内。

对原图归一化坐标 u 和 v，椭圆距离 r 为两项平方和的平方根，两项分别是 u 与 centerX 的差除以 radiusX，以及 v 与 centerY 的差除以 radiusY。

权重 M 为 1 减 smoothstep 在 1 减 feather 与 1 之间对 r 的结果。椭圆外权重严格为 0。disabled 区域权重为 0。

每个区域从相同的 G 开始。先乘局部曝光增益，再按曝光后的亮度计算高光权重并应用 highlights，随后执行局部 saturation，得到 L。最终线性颜色为 G 加所有区域的 M 乘 L 与 G 的差。最后统一限制到 0 至 1 并编码输出。

所有区域独立从 G 计算，区域列表顺序不影响画面。重叠区域的变化累加，UI 必须显示重叠轮廓。首版不提供图层排序。四个局部区域全部为零参数时，输出应与无局部区域一致。

## 坐标与 Transform

规范化原图左上为原点，x 向右，y 向下。原图尺寸记为 W 和 H，区域几何使用除以 W 和 H 的归一化坐标。VLM 的所有区域坐标都引用完整规范化原图。

angleDeg 为顺时针旋转角度，范围负 10 至正 10，步长 0.1。旋转围绕原图中心进行。旋转后外接画布宽度为 W 乘余弦绝对值加 H 乘正弦绝对值，高度为 W 乘正弦绝对值加 H 乘余弦绝对值，分别记为 Wr 与 Hr。

crop 包含 x、y、width、height，均为旋转后外接画布上的归一化坐标。x 与 y 范围为 0 至 1，width 与 height 大于 0 且不超过 1，x 加 width 和 y 加 height 均不超过 1。crop 保留至小数点后 8 位，几何计算保留双精度，入 GPU 时转换为浮点。默认角度为 0，默认 crop 为 x 等于 0、y 等于 0、width 等于 1、height 等于 1。

aspectLock 枚举为 free、original、square、portrait4x5、landscape3x2、wide16x9。默认 original。original 使用 W / H，其余分别为 1、4 / 5、3 / 2、16 / 9。实际比例由 width 乘 Wr 除以 height 乘 Hr 得出。锁定比例时，以裁切像素高度乘目标比例得到理论宽度，与实际裁切像素宽度的差不得超过 0.01 像素，整数输出允许最终舍入误差。

输出坐标为裁切矩形中的像素中心，先还原到旋转画布像素位置，再减旋转画布中心，应用负 angleDeg 的二维旋转，最后加原图中心。所得位置用于取色与区域权重计算。GPU 的纹理垂直方向转换仅在采样边界处理一次。

合法裁切必须满足全部四个角逆变换后均落在原图范围内，边长至少对应原图空间 64 像素，面积大于 0。允许 0.01 原图像素的浮点误差，超出后拒绝。AI 裁切还需满足输出面积至少为 W 乘 H 的百分之四十。

手动改变旋转角度时，先把原裁切中心映射到新的旋转画布，再保持所选像素比例，寻找以该中心为中心的最大合法同比缩小矩形。中心落在可行区域外时先移到旋转后原图中心。使用四角约束和确定性二分求缩放比例，直到误差小于 0.01 像素。界面实时显示实际裁切。

模型发送 transform 时必须提供完整 angleDeg、crop 和 aspectLock，服务器和浏览器严格验证，非法矩形整体拒绝，不暗中修正模型意图。

## 事务、历史和候选计划

事务包含 transactionId、source、beforeSnapshot、afterSnapshot 和 changeSummary。source 枚举为 manual、ai、reset。快照包含全部可编辑字段，revision 独立管理。图像资源不复制。

滑杆拖动过程中维护临时手动状态，松开时提交一个事务。键盘连续调整在焦点离开或连续 300 毫秒无输入后合并提交。取消拖动恢复 beforeSnapshot。提交前后相同则忽略。

AI 提交使用字段赋值，值表示目标绝对值。例如当前曝光 0.30，再亮一点的计划可以赋值 0.45。不得把 0.45 解释为增量。

候选计划记录 imageId、baseRevision、requestId、planId 和完整变更集。应用时四项必须与活跃候选对应，baseRevision 必须等于当前 revision。整个变更集原子执行，一个 AI 建议产生一个历史事务。planId 被应用后立即消费，重复点击无效。

撤销与重做恢复可编辑快照，但 revision 始终递增。手动拖动开始、数值输入首次改变、撤销、重做、重置和换图都会使进行中的 AI 请求失效，禁止等到手动事务提交时才处理。候选预览禁止写入已提交状态，放弃预览直接恢复当前状态。

## 缩略图与分析坐标

AI 原图缩略图来自规范化原图，效果缩略图应用全局和局部参数，强制 angleDeg 为 0 且 crop 为完整图。请求另外携带实际 transform。这样两张图片共用原图坐标，避免模型把裁切后坐标误用于局部区域。

两张缩略图长边最多 1024，JPEG 质量 0.85，不携带 EXIF、GPS、文件名或路径。两图二进制合计超过 1.5 MiB 时，请求准备失败并显示原因。不得私自上传原图补充细节。

## 导出契约

导出开始时使进行中的 AI 请求失效，并冻结 imageId、revision、EditState 和输出设置。候选计划必须先应用或放弃。导出期间禁用修改、AI 请求和替换照片，允许取消导出。所有输出由冻结状态计算。

裁切原始尺寸分别为 crop.width 乘 Wr 和 crop.height 乘 Hr，四舍五入到最近正整数。指定长边时保留比例且禁止放大。像素宽高为整数，默认使用原始裁切尺寸。

GPU 按最多 2048 像素边长的输出块渲染。每块的像素坐标必须使用完整导出画面的全局偏移，避免接缝。原图仍以完整纹理参与采样。按块 readPixels 并进行一次上下翻转，写入输出 Canvas 2D；浏览器可编码 JPEG、PNG、WebP 与 AVIF，TIFF 使用无压缩 RGBA 编码。

输出画布仍需要完整输出像素内存。G0 必须验证目标设备的 2400 万像素画布和所选格式编码能力。能力不足时报告 EXPORT_RESOURCE_LIMIT，并由使用者选择较小尺寸重新导出。首版不提供静默降采样。

文件名取本地原文件基本名加 edited 后缀和所选格式扩展名。输出为 sRGB 像素，不写 GPS、拍摄日期和设备信息。JPEG、WebP 与 AVIF 为有损编码；PNG 与 TIFF 用于保留无额外有损压缩的中间结果。导出结束释放块缓冲、输出画布和临时 Blob 引用。

## 一致性与性能目标

相同原始像素、状态和版本应产生数值一致的编辑含义，跨 GPU 允许有限浮点误差。禁止承诺不同浏览器 JPEG 字节完全一致。

预览与导出一致性使用相同输出尺寸下、编码前的 RGBA 比较。平均每通道绝对差不超过 1 个 8 位等级，第 99 百分位不超过 3 个等级。缩小预览与大图缩小后的结果另行视觉评审，缩放滤波引起的差异单独报告。

参考设备为 16 GB 内存且启用硬件加速的桌面电脑，具体 CPU、GPU、操作系统和浏览器版本必须记录。2048 长边预览在 4 个局部区域下，滑杆输入至可见更新第 95 百分位低于 50 毫秒。2400 万像素 JPEG 导出目标低于 15 秒，成功解码到首帧目标低于 3 秒。以上均为待实测目标。
