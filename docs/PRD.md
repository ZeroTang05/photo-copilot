# 产品需求文档

## 用户与任务

主要使用群体为拥有手机或相机照片、理解明暗和色彩偏好、缺少专业修图经验的摄影爱好者。主要任务覆盖旅行风景、日常人像、城市夜景和生活记录。

典型任务包括让逆光人物更明亮、让天空的高光柔和、收紧松散构图、保留现场氛围，以及在 AI 建议后继续调节强度。成片是否符合意图和是否能够自主修正，比参数数量更重要。

## 产品界面

页面采用深灰中性工作区，图片周围避免强烈彩色背景影响判断。桌面布局包含顶部工具条、左侧缩略图栏、中央画布、右侧参数面板和底部 AI 面板（仅占左下，不延伸至参数栏下方）。参数面板默认宽 320 CSS 像素，AI 面板默认高 240 CSS 像素，可收起。1024 宽度下参数面板可收起，画布保持可操作区域。

顶部提供导入、撤销、重做、对比、缩放和导出。左侧缩略图栏支持当前会话多张图片并存，可点击切换；激活图缩略图带强调色边框。参数面板包含构图、光线、色彩、局部调整四组。AI 面板包含输入框、建议卡和最近会话。高级信息默认折叠，关键改动通过建议卡直接展示。

参数面板按自有 SPEC + 设计图扩展组织。`画笔`、`渐变`、`径向` 当前未纳入 SPEC，以禁用占位控件展示，等待加入后再启用；其余参数已落地，命名与含义与 Lightroom/Capture One/DaVinci Resolve 的行业共识对齐，详见 `docs/COLOR-GRADING.md`。

初始页展示导入入口和文件范围。文件进入后立即显示本地预览。AI 建议由明确点击触发，首次触发时展示缩略图发送说明。

## 主流程

1. 使用者选择或拖入照片，系统验证并解码，画布显示规范化图像。
2. 使用者点击分析并建议，也可输入希望保留或改变的风格。
3. 首次 AI 使用弹层说明缩略图、当前编辑参数和输入文字会发送至模型服务，原始文件保留在当前标签页。
4. 系统显示可取消的分析状态，完成后以候选状态渲染画布和参数面板。
5. 建议卡显示至多 3 项观察及对应变更，提供应用建议和放弃建议。
6. 应用后创建一个历史节点。使用者继续输入局部方向或手动调整。
7. 导出面板展示格式、尺寸、预计像素数与元数据规则，导出本地文件。

候选预览期间，参数面板显示候选值且编辑控件禁用，画布上的缩放、平移和对比仍可使用。应用或放弃后恢复编辑。这样可以清楚地区分建议与已提交结果。

## 功能与验收

| 编号 | 行为要求 | 可观察验收 |
| --- | --- | --- |
| FR-01 | 支持选择和拖入，替换照片前提示当前编辑将结束，成功解码后才替换旧会话 | 损坏图片、伪造扩展名、超限图片均显示原因且保留旧图 |
| FR-02 | 滚轮缩放，拖动画布，双击适应窗口，提供数值缩放入口 | 改变缩放与平移不产生历史节点 |
| FR-03 | 滑杆、数值输入和单项归零共用相同参数状态 | 一次拖拽产生一个历史节点，取消输入恢复先前值 |
| FR-04 | 比例提供自由、原图、正方形、四比五、三比二、十六比九，调平后自动缩小可用裁切范围 | 导出无透明角，无越界采样，固定比例误差至多一个输出像素 |
| FR-05 | 初次建议默认保持比例和构图，明确开启构图建议后允许裁切和调平 | 未开启构图建议时 AI 返回构图变更会被拒绝 |
| FR-06 | 更暖一点、更自然、太阳附近暗一点等指令产生当前状态上的建议 | 未涉及字段保持原值，连续追问不会重置已有裁切 |
| FR-07 | 展示区域名称、轮廓、羽化覆盖，提供添加、移动、缩放、隐藏、删除和参数调节 | 改变裁切和旋转后蒙版仍跟随同一原图内容 |
| FR-08 | 解释关联具体参数和区域，数值差异从真实状态计算 | 卡片展示值与实际应用值完全一致 |
| FR-09 | 撤销与重做支持快捷键，原始状态可一键重置 | 撤销 AI 计划一次恢复完整修改前状态 |
| FR-10 | JPEG 导出，默认质量 0.92，允许 0.80 至 1.00，尺寸显示为整数像素，导出开始时取消进行中的 AI 请求 | 原尺寸导出基于规范化原图，导出不包含 EXIF 和 GPS |
| FR-11 | 请求期间允许手动编辑，编辑导致对应请求失效并发出取消 | 迟到结果显示已过期，参数和历史均不变化 |
| FR-12 | 未同意发送前保持本地操作,无邀请码门槛,AI 默认可用 | 本地调节和导出在模型断网时仍可完成 |

## 自然语言语义

全局指令更亮一点优先修改全局曝光。局部指令太阳附近暗一点优先生成或更新太阳附近椭圆，默认保持其他参数。明确提到已有区域名称时引用现有区域 ID。目标重叠或存在多个候选时返回一个简短澄清问题，并保留当前画面。

人像边缘、衣物边界或复杂天空的精细选区不能由首版椭圆保证。建议卡应说明区域覆盖范围可调整。要求精确避开主体时，如现有区域无法满足，返回限制说明和手动画区建议。

电影感、清新、自然等风格词转化为支持的光线和色彩操作。风格词不隐含改变画幅比例。移除路人和换天空等指令返回能力范围提示。

示例解释采用完整句子。太阳附近较亮，降低该区域曝光可以减弱视觉吸引力。区域边缘覆盖了少量天空，可以拖动范围继续调整。不得声称已经恢复原图缺失的纹理。

## 状态和异常体验

| 状态 | 可进行的操作 | 展示内容 |
| --- | --- | --- |
| 空闲 | 导入 | 文件支持范围 |
| 解码中 | 取消新导入 | 解码进度状态，旧图保持可见 |
| 可编辑 | 调节、AI、导出 | 当前已提交效果 |
| AI 请求中 | 手动编辑、取消、导出当前状态 | 处理中和取消入口 |
| 候选预览中 | 应用、放弃、对比、缩放 | 建议效果和待应用标识 |
| 导出中 | 取消导出 | 本次导出尺寸和阶段进度 |
| GPU 失效 | 尝试重新建立渲染器 | 当前参数仍在内存，无法渲染的原因 |

AI 超时提示本次建议未完成，并提供重新请求。额度耗尽显示下次恢复时间。局部区域达到上限时提示删除已有区域。导出资源不足时显示失败原因并提供由使用者选择较小尺寸的入口。

首版没有自动持久化。首次导入后工作区显示关闭或刷新页面会结束当前编辑。关闭页面时在浏览器允许的范围内使用离开提醒。图片导出成功不代表编辑项目已保存。

## 历史与对比

历史保存最近 100 个事务的参数快照和来源。达到上限后移除最早可撤销节点，保留原始基线用于重置。重置本身是一次事务，可以撤销。撤销后新增编辑会清空重做分支。

按住对比按钮展示相同裁切与旋转下的原始色彩，松开恢复当前预览。另提供查看完整原图入口，用于评估构图变化。对比状态不可写入历史或导出。

## 可访问性

所有滑杆有中文名称、数值和键盘步进。Tab 可访问按钮、输入框和区域列表。焦点明确可见，错误以文字表达。Ctrl 或 Cmd 加 Z 撤销，加 Shift 加 Z 重做，输入文字时优先采用输入框编辑行为。区域拖动同时提供中心与尺寸的数值输入。

## 产品指标

核心指标为成功导出会话占有效导入会话的比例。有效导入会话指成功解码且停留至少 10 秒的会话。邀请试用的探索目标为百分之五十。

辅助指标包括首次建议应用率、应用后连续两步内撤销率、局部区域修正率、首次导出耗时、成功导出的平均调用成本。建议应用率目标为百分之六十，快速撤销率目标低于百分之二十五。所有指标在报告中同时给出分子、分母和样本量。

首版研究通过自愿的试用记录和访谈收集。默认不部署第三方行为分析 SDK。服务端运行日志记录用量和错误，内容字段遵循 AI-WORKFLOW。
